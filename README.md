# TFG: Método de Elementos Finitos en Julia

Trabajo de Fin de Grado sobre implementación del Método de Elementos Finitos usando Julia para el código numérico y Python/Manim para las presentaciones.

## Estructura
- `src/julia/`: Código de elementos finitos
- `src/python/`: Animaciones con Manim
- `docs/`: Documentación
- `tests/`: Tests unitarios
